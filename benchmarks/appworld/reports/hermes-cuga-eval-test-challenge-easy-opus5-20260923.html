What matches the Harbor run

The actual Hermes CLI runs its own loop, uses the same Opus 5 model identifier and 25-turn cap, discovers AppWorld functions through native MCP, and calls the supervisor completion tool.

What differs from Harbor

Harbor scheduled containerized trials with an AppWorld sidecar and two-way concurrency. Here, CUGA Eval runs tasks sequentially against its local AppWorld services and launches a fresh isolated Hermes home/workspace for each task.

Answer and score path

The adapter extracts the exact answer from the nested supervisor__complete_task call when present, falls back to Hermes's final message when necessary, then CUGA Eval submits that answer and runs world.evaluate(). No judge model determines task success.
